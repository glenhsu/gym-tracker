# 🏋️ 重訓日記 - Gym Workout Tracker

一個輕量級、離線可用的訓練追蹤網頁應用。所有資料存在瀏覽器的 localStorage，無需後端伺服器。

## 功能特色

- 💪 **訓練範本** — 建立和管理訓練計畫（推日、拉日、腿日等）
- 🏋️ **即時訓練** — 從範本開始訓練，記錄每組次數與重量
- ⏱️ **休息計時器** — 組間自動倒數，最後 3 秒有提示音
- 📜 **訓練紀錄** — 完整的歷史記錄，包含訓練量統計
- 🏆 **PR 排行榜** — 自動計算 1RM，追蹤個人最佳紀錄
- 🌙 **深色主題** — 夜間訓練不刺眼
- 📱 **PWA 友善** — 支援行動裝置，可加入主畫面

## 使用方式

直接開啟 `index.html` 即可使用，無需安裝任何東西。

## 技術

- 純 HTML/CSS/JavaScript 單頁應用
- 使用 localStorage 儲存資料
- Font Awesome 圖示（CDN）
- Epley 公式計算 1RM
